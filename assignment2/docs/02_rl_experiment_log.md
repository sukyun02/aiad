기준 학습 세 개와 D1은 모두 `QTRACE=1`, 수집 횟수 0으로 실행했다. 네 학습 로그 모두 `Training: cuda; continue baseline.pth`를 확인했고, epochs 5 / batch 64 / conservative_weight 0.1은 유지했다. 실행은 한 작업씩 순서대로 했으며, 재개 후 각 학습·rollout 직전 가용 메모리는 23~24GiB였다. 오류·killed/OOM·학습 출발점 불일치는 없었다. 앞선 준비 과정의 Codex `bwrap` 초기화 오류는 실행 환경 변경 후 발생하지 않았다.

`verify.py`(kit으로 실행)의 확인 31개가 모두 통과했다.

1. 각 파일은 C 파일에서 `REWARD_SETTINGS` 줄과 `calculate_reward()`의 `return` 앞에 넣은 줄(R1 7줄, R1b·R2 3줄)만 다르다.
2. `REWARD_SETTINGS`는 제공값을 그대로 두고 위 표의 값만 더했다.
3. 공식 `model_definition`이 C 파일과 같고 baseline과 다르다. 구조는 C이고 처음부터 학습한다.
4. 두 묶음의 모든 스텝(60개 에피소드, 147,039스텝)에서 제공 `network.py`가 저장된 보상을 그대로 다시 만든다(차이 0). 다시 매기기와 같은 순서(에피소드를 폴더 순서로 한 프로세스에서)로 계산한 각 후보의 보상은, 에피소드마다 따로 쓴 식과 모든 스텝에서 같다(차이 0).
