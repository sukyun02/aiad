크기는 출력 확인의 시작점이다. **넘치면 내용을 더 줄이고, 8pt대 본문이나 3페이지로 되돌아가지 않는다.** 중요한 수치와 절 제목 외에는 굵은 글씨를 줄인다.

### 그림 때문에 생긴 공백과 페이지 분할 해결

1. **그림 1을 먼저 조정한다.** 오른쪽 열의 폭을 현재 41%에서 약 30~32%로 줄이는 것부터 시험한다. 비율을 유지하며, 실제 관측 화면 높이는 약 42~48mm, 범례·캡션까지는 약 55~60mm를 시작점으로 본다. 숫자는 고정 규격이 아니라 실제 크기에서 읽히는지 확인할 조정값이다.
2. **왼쪽 열에 마지막 수집 설명도 포함한다.** 현재 두 열 아래에 따로 있는 후보 선택·수집량 문단을 방법·탐색 설명과 묶는다. 내용을 새로 추가해 공백을 메우지 않는다.
3. **그림 원본의 불필요한 테두리 공간도 확인한다.** 그림 자체에 공백이 있으면 정리하되 도로·차량·목표점 같은 근거는 자르지 않는다. 범례를 작게 만들어 억지로 맞추지 않는다.
4. **상단은 제목과 인적 사항을 유지하면서 간격을 조정한다.** 제목과 우측 과목명 배치를 정렬하고 결과 상자 전후 여백을 조금 줄인다. 큰 19.10초 숫자를 줄여 공간을 만드는 것은 뒤로 미룬다.
5. **3절을 위한 공간을 먼저 확보한다.** 제목·3행 표·캡션·선택 이유·설정을 합쳐 약 55~60mm가 필요하다고 보고 1쪽을 배치한다.
6. **3절 전체에 분할 방지를 적용한다.** 제목만 또는 표만 보호하지 말고 하나의 절 묶음으로 감싼다. 3절이 들어간 것을 확인한 뒤 4절 앞에서 2쪽을 시작한다.
7. **모든 절에 일괄 분할 방지를 걸지 않는다.** 큰 묶음이 통째로 밀리면 오히려 빈 공간이 늘어난다. 이 지침은 짧은 3절을 우선 대상으로 한다.

## 4. 문체: 실제로 한 일과 결과를 직접 쓰기

서술형은 과제1과 맞춰 “했습니다”로 통일한다. 수집한 사실과 측정한 숫자가 문장의 중심이 되게 한다. 없는 경험이나 감상을 만들어 사람처럼 보이게 하지는 않는다.

| 길고 추상적인 표현 | 짧게 바꾼 예 |
|---|---|
| “이번 실험 범위에서는 수집 경로의 품질이 성능을 좌우한 주요 요인으로 관찰됐습니다.” | “수집 경로를 줄이자 모델 기록도 19.40초에서 19.10초로 줄었습니다.” |
| “고속 주행의 시범 데이터를 확보하기 위해 화면 기반 경로 추종 규칙을 도입했습니다.” | “모델이 첫 코너를 넘지 못해, 직접 작성한 경로 추종 제어기로 데이터를 모았습니다.” |
| “기본 보상을 유지하고 개선 효과가 확인된 수집 경로에 집중했습니다.” | “중앙선 보상을 없애도 기록이 같아 기본 보상을 유지했습니다.” |
| “행동 선택을 조향에 집중시키는 설계입니다.” | “가속 행동에 점수를 더해 조향을 고르도록 했습니다.” |

- 절 번호 아래에 굵은 소제목을 매 문단마다 붙이지 않는다. 문장 자체가 앞뒤 내용을 이어 주도록 쓴다.
- “방법·의의·효과·한계”를 모든 절에서 같은 순서로 반복하지 않는다.
- 괄호에는 꼭 필요한 값이나 인용만 넣는다. 구현 변수명·예외·해석을 한 괄호 안에 겹쳐 쓰지 않는다.
- “나아졌다”만 쓰지 말고 무엇이 얼마나 달라졌는지 적는다. 반대로 모든 측정값을 본문에 나열하지는 않는다.
- 수집용 제어기 사용, 반복 실험의 차이, 고정 트랙이라는 한계는 남긴다. 문장을 짧게 만드는 과정에서 결과를 과장하지 않는다.
- “규칙과 같은 기록”을 “아무 효과 없음”으로 확대하지 않는다. 특히 V1P5는 랩타임 추가 개선은 없었지만 별도 진단의 경계 여유는 달랐다.

### 용어를 먼저 정의하고 일관되게 사용하기

- **처음 등장:** ‘직접 작성한 수집용 경로 추종 제어기(규칙 기반 수집 정책)’로 설명한다.
- **이후 본문:** ‘수집용 제어기’, 행동 선택 전체를 말할 때는 ‘수집 정책’이라고 쓴다. 탐색 시에는 제어기 행동 대신 무작위 조향을 선택할 수 있다.
- **학습 결과:** ‘학습 모델’ 또는 ‘제출 모델’로 부른다. 수집용 제어기가 제출 시 직접 운전한다고 오해하게 만들지 않는다.
- **run:** 본문에서는 ‘실험 1회’ 또는 ‘반복 실험’으로 바꾼다. 여기서 실험 1회는 수집·학습을 10사이클 진행한 전체 과정이다. 단 한 번의 학습 호출을 뜻하지 않는다.
- **‘규칙만’ 열:** ‘수집용 제어기 단독’으로 바꾸고 ε=0이라는 조건을 주석에 둔다.
- **‘깨끗함’:** 첫 사용 때 ‘완주·273/273·이탈 0’으로 정의한다.

‘규칙 기반 제어기(rule-based controller)’는 실제 연구에서 사용하는 표현이다. 하지만 [과제 README](../README.md)는 이를 공식 방법명으로 정하지 않고 `collection_action()`을 ‘데이터 수집 중 행동을 선택하는 방법’으로 설명한다. 따라서 이름만 쓰기보다 무엇을 직접 구현했는지 밝혀야 한다. 용어 확인용 연구 예시는 [Likmeta et al., 2020](https://doi.org/10.1016/j.robot.2020.103568)이며, 이 문헌을 제출 참고문헌에 추가할 필요는 없다.

### 내부 식별자와 보고서용 이름의 대응

**다음 이름은 서로 다른 CNN 구조의 이름이 아니라, 수집 방식을 달리해 학습한 모델을 구분하는 설명형 이름이다.** 주요 단계의 CNN 구조·보상·학습 설정은 같았다고 표 캡션에서 한 번 설명한다.

| 내부 식별자 | PDF에서 사용할 이름 | 이름이 가리키는 차이 |
|---|---|---|
| baseline | 제공 모델 | 과제에서 제공한 가중치 |
| V1R | 도로 중앙 조준 모델 | 영상의 한 행에서 도로 가운데를 찾아 조준한 데이터로 학습 |
| V1P | 중심 경로 추종 모델 | 여러 경로점을 이어 도로 중심을 추적한 데이터로 학습 |
| V1P2 | 코너 단축 모델 | 조준 거리를 조절하고 목표점을 안쪽으로 옮긴 데이터로 학습 |
| V1P3a | 완만한 코너 개선 모델 | 완만한 코너에서 안쪽 이동을 늘린 데이터로 학습 |
| V1P4 | **스플라인 방향 추정 모델(최종)** | 경로 방향을 삼차 평활 스플라인의 접선으로 계산하고 코너 판정값도 조정 |
| V1P5 | 안쪽 이동량 조정 모델(추가 비교) | 최종 수집용 제어기의 안쪽 이동량 계산 파라미터를 추가 조정 |

- 이 대응표는 작성자 참고용이다. PDF 본문·표·그림에는 오른쪽의 설명형 이름을 사용하고, V1P2·V1P4를 반복해서 병기하지 않는다.
- 내부 식별자·파일명·실험 원장은 바꾸지 않는다.
- 그래프 범례는 **‘코너 단축 모델(19.20초)’ / ‘스플라인 방향 추정 모델(19.10초)’**로 통일한다.
- 표에서 행 이름에 ‘모델’이 반복돼 길어지면 열 제목을 ‘학습 모델’로 두고 각 행의 ‘모델’을 생략한다.
- ‘스플라인 모델’만 쓰면 CNN 내부에 스플라인 층을 넣은 것처럼 보일 수 있으므로 ‘방향 추정’이라는 말을 남긴다. 스플라인은 수집용 제어기에서 사용한다.

## 5. 최종 PDF 본문 구성

양식의 다섯 절과 번호를 유지한다. 아래 길이는 설명문 기준이며 표·그림·수식은 별도다.

### 1. 데이터 수집 및 탐색 전략 — 짧은 문단 2~3개 + 그림 1

**남길 내용**

1. 배경 한 문장: 모델이 직접 수집한 실험의 최고 기록은 39.80초였고, 가속을 고정한 초기 모델은 첫 코너를 넘지 못했다.
2. 방법: 직접 작성한 수집용 경로 추종 제어기로 회색 도로 영역에서 경로점을 잇고, 삼차 평활 스플라인으로 방향을 읽어 코너 안쪽의 목표점을 정했다.
3. 탐색: 확률 0.9로 제어기 행동을 사용하고, 0.1로 가속을 유지한 좌·직진·우 중 하나를 무작위로 골랐다.
4. 선택 이유: 고속 주행 데이터를 모으려는 구성이며, ε=0.1은 제공값을 유지했다.
5. 선별·수집: 제어기 단독 랩타임과 탐색 중 깨끗한 완주 비율로 후보를 골랐다. 최종 제어기의 선별 평가는 17/20이었고, 수집·학습 실험을 두 차례 진행하며 각 실험에서 총 120회 수집을 시도했다.

마지막 두 통계가 과밀하면 17/20을 빼고 수집 규모만 남긴다. 17/20과 실제 수집의 192/240은 다른 집계이므로 합쳐 쓰지 않는다. 선별·수집 설명은 그림 아래 별도 행으로 밀어내지 말고 왼쪽 설명에 포함한다.

제어기를 수집에만 쓴다는 설명은 상단에 이미 있다. 여기서는 도로 영역 추출이나 스플라인이 CNN의 별도 입력 또는 추론 단계인 것처럼 보이지 않게 한다.

**그림 1: 수집용 제어기가 보는 화면**

- 실제 화면, 경로점, 방향 추정 곡선, 목표점만 표시한다. 긴 변수명과 수치를 그림 안에서 줄인다.
- 범례는 ‘경로점 / 방향 추정 / 목표점’처럼 짧게 쓴다. 필요하면 이동 전 목표점은 작은 빈 점으로만 표시한다.
- 예시 캡션: **그림 1. 수집용 제어기의 도로 추적과 목표점. 스플라인은 방향 추정용이다.**
- 본문과 그림은 고정된 두 칸으로 두되 **그림 약 30~32%, 본문 나머지 폭**을 시작점으로 맞춘다. 그림의 높이와 왼쪽 설명의 높이가 비슷하게 되도록 한다.
- 그림 원본의 불필요한 공간, 범례, 캡션을 정리하고 실제 인쇄 크기에서 표식이 읽히는지 확인한다. 여백을 채우려고 그림을 더 키우지 않는다.

### 2. 보상함수 설계 — 수식 한 줄 + 설명 2~3문장

사용한 기본 보상:

```text
보상 = 새 타일 수 × (1 + 0.5 × 중앙 근접도) − 0.5 × 도로 이탈 여부
```

- 중앙 근접도는 0~1이고, 시간 벌점과 완주 보너스는 0이다.
- 중앙선 가점을 없앤 비교도 최고 19.40초에 머물러 기본 보상을 유지했다.
- ‘보상이 영향 없었다’라는 일반적인 결론은 쓰지 않는다.

이 수식과 유지 이유로 보상 항목·가중치·선택 이유를 설명한다.

### 3. 모델 구조 — 제목부터 학습 설정까지 한 페이지에 배치

**3절 제목·표·캡션·선택 이유·학습 설정을 하나의 묶음으로 둔다. 우선 1쪽 안에서 모두 마친다.**

**표 1. 제공 모델과 제출 모델의 구조**

| 구분 | 제공 모델 | 제출 모델 |
|---|---|---|
| 영상 특징 | 합성곱 1층 + 평균 풀링 | stride 2 합성곱 4층 + 펼친 특징에 LayerNorm |
| 행동 점수 | 영상 특징·센서 7개 → 선형층 | 영상 특징·센서 7개 → 은닉층 128 + LayerNorm → 9개 점수 |
| 가속 | 학습 가능한 가속 head | head 제거, 가속 행동 1·5·6에 +5 |

- 공간 특징을 표현할 네 층 CNN과 학습 안정화를 위한 LayerNorm을 사용했다고 설명한다. Q 증가를 막았다고 입증한 것은 아니다.
- 센서 7개도 관측 영상에서 읽는다. 도로 마스크나 스플라인을 모델에 넣는 것으로 설명하지 않는다.
- 설정 한 줄: **보수항 3.0 · γ 0.99 · 학습률 3e−4 · epochs 5 · batch 64**.
- 합성곱의 채널 수 `16→32→64→64`는 공간이 허용하면 첫 행에 추가한다. 모든 커널 크기·행렬 차원을 나열할 필요는 없다.

### 4. 학습 및 주행 결과 — 2쪽 시작, 결과 표는 3열로 축소

**표 2. 수집 방식에 따라 학습한 모델의 랩타임**

| 학습 모델 | 수집용 제어기 단독 (초) | 학습 모델 최고 (초) |
|---|---:|---:|
| 제공 모델 | — | 47.02 |
| 도로 중앙 조준 | 19.40 | 19.40 |
| 중심 경로 추종 | 19.26 | 19.26 |
| 코너 단축 | 19.22 | 19.20 |
| 완만한 코너 개선 | 19.14 | 19.12 |
| 스플라인 방향 추정(최종) | 19.12 | **19.10** |

**결과 표의 시각적 우선순위**

- ‘다른 run의 최고’ 열은 삭제한다. 학습 모델의 기록은 **방식별 수집·학습 실험 2회 중 최고 깨끗한 기록**으로 통일한다.
- 제어기 단독 기록은 ε=0으로 제어기 자체가 주행한 값이다. 이를 학습 모델이나 서버 결과와 혼동하지 않게 한다.
- **최종 19.10만 크게 또는 진하게 강조**한다. 최종 행 전체를 굵게 만들지 않는다.
- 캡션은 한두 줄: **제어기는 ε=0, 모델은 방식별 실험 2회 중 최고 깨끗한 기록이다. 주요 비교 모델의 CNN·보상·학습 설정은 같으며, 제공 모델은 비교용 한 쌍이다.**
- ‘깨끗한 기록 = 완주·273/273·이탈 0’은 이 절에서 한 번만 정의한다.

반복 간 차이는 별도 열 대신 다음 짧은 주석으로 남긴다.

> 최종 수집 방식으로 실험한 두 모델의 최고 기록은 19.10초와 19.12초였습니다.

그다음 확인 결과를 한 문장으로 적는다.

> 제출 쌍은 로컬 CPU·CUDA와 공식 infer.py에서도 19.10초로 완주했습니다.

c4에서 고른 가중치가 c10까지 유지됐다는 상세 이력은 작성자 자료에 남긴다. 본문에서 여러 번 재현한 결과인 것처럼 쓰지만 않으면 사이클 식별자를 나열할 필요는 없다. 서버 기록은 상단에 있으므로 반복해서 긴 문단으로 설명하지 않는다.

**그림 2: 코너 단축 모델과 스플라인 방향 추정 모델의 비교**

- 회색: **코너 단축 모델(19.20초)**. 강조색: **스플라인 방향 추정 모델(19.10초)**.
- 독자가 내부 식별자를 몰라도 비교를 이해하도록 V1P2·V1P4 대신 위 이름을 범례·캡션·본문에 동일하게 사용한다.
- “같은 CNN에서 수집 방법을 바꿔 학습했다”는 점을 표 캡션에 이미 설명했으므로 그래프에서 다시 길게 반복하지 않는다.
- 모든 막대에 숫자를 붙이지 말고 핵심 구간 2·3·5를 우선 표시한다. 0 기준선과 음수 값은 유지한다.
- 19.06초라는 비교 경로 기록은 캡션에만 두어 최종 제출 기록과 경쟁하지 않게 한다.
- 캡션: **그림 2. 측정용 19.06초 경로 대비 구간 시간 차이. 비교 경로는 트랙 좌표를 읽으며 진단에만 사용했다.**
- 해석 한 문장: **완만한 코너가 있는 구간 2·3·5의 시간 차이가 합계 108ms에서 43ms로 줄었고, 구간 4도 개선됐습니다.**
- 두 모델 사이에는 완만한 코너의 이동량 조정도 포함돼 있다. 누적된 개선을 스플라인 하나만의 효과라고 설명하지 않는다.

그림 제작 수치는 기존 `sections.jsonl`을 사용한다. 이름만 바꾸며 데이터와 비교 대상은 바꾸지 않는다.

### 5. 결과 분석 — 짧은 문단 2개, 별도 실패 표 없음

**첫 문단: 개선 이유와 추가 비교**

- 속도가 상한 부근인 주행에서 수집 경로를 줄이는 데 집중했고, 학습 모델 기록이 19.40→19.10초로 개선됐다고 쓴다.
- 추가 비교는 필요한 세 가지로 줄인다: 모델 수집·중앙선 보상 변경은 19.40초, 보수항·할인율 변경은 19.12초를 넘지 못했고, **안쪽 이동량 조정 모델**의 두 실험도 19.10초로 제출 모델과 같았다.
- 1° 후보 간격, 급전환 완화, 후보 60개의 상세 도달 횟수는 PDF에서 뺀다. 근거는 02 문서에 남아 있다.

**둘째 문단: 실패와 한계**

- 수집용 제어기가 경계에 가까운 경로를 택할수록 탐색 중 이탈이 늘었던 점을 대표 실패 사례로 쓴다.
- 직접 작성한 제어기에 대한 의존, 같은 고정 트랙에서의 개발·평가, 구성당 실험 2회라는 한계를 짧게 묶는다.
- 제출 모델의 92.5% 코너 바퀴 여유 약 0.09는 근사 진단값이라고 밝힌다.
- **‘수집용 제어기의 성능을 크게 넘어서는 경로 개선은 확인하지 못했다’**로 쓴다. 한 스텝 빨랐던 사례와 모순되지 않게 한다.

안쪽 이동량 조정 모델은 두 실험 모두 최고 19.10초였으며 **제출 모델은 스플라인 방향 추정 모델 그대로**다. 다른 진단 지표까지 모두 같았다고 쓰지 않는다.

| 쪽 | 구성 | 배치 기준 |

### 참고문헌

PDF에는 아래 네 편의 축약 서지만 넣고 설명 문장은 제외한다. 본문에서 실제로 사용하는 문장 끝에 [1]~[4]로 연결한다.

1. Hester et al. _Deep Q-learning from Demonstrations_. AAAI, 2018. [원문](https://ojs.aaai.org/index.php/AAAI/article/view/11757) — 시범 데이터 활용의 동기. DQfD의 지도 손실을 구현했다고 쓰지 않는다.
2. Kumar et al. _Conservative Q-Learning for Offline Reinforcement Learning_. NeurIPS, 2020. [원문](https://proceedings.neurips.cc/paper_files/paper/2020/hash/0d2b2061826a5df3221116a5085a6052-Abstract.html) — 제공된 보수항의 근거. 규칙 복제를 보장한다고 설명하지 않는다.
3. Yue et al. _Understanding, Predicting and Better Resolving Q-Value Divergence in Offline-RL_. NeurIPS, 2023. [원문](https://proceedings.neurips.cc/paper_files/paper/2023/hash/bd6bb13e78da078d8adcabbe6d9ca737-Abstract-Conference.html) — LayerNorm 도입 동기. 논문 결과와 이 과제의 관찰을 구분한다.
4. Green & Silverman. _Nonparametric Regression and Generalized Linear Models: A Roughness Penalty Approach_. Chapman & Hall, 1994. [서지 정보](https://research-information.bris.ac.uk/en/publications/nonparametric-regression-and-generalized-linear-models-a-roughnes/) — 자연 삼차 평활 스플라인의 방법 근거.
