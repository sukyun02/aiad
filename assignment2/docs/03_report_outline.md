## 작성 방향과 범위

- 중심 범위는 **규칙 수집 V1R → V1P → V1P2 → V1P3a → V1P4**다. 모든 실험의 연대기를 나열하지 않고, 고속 주행 데이터 확보와 경로 개선이 학습한 정책에 어떻게 반영됐는지를 설명한다.
- 규칙 도입 전 실험은 배경 두 문장으로 압축한다. LayerNorm과 보상 선택에 필요한 근거는 해당 절에서 짧게 보충한다.
- 양식의 다섯 절을 그대로 사용한다: **데이터 수집 및 탐색 전략 / 보상함수 설계 / 모델 구조 / 학습 및 주행 결과 / 결과 분석**.
- 1~3절은 방법과 선택 이유, 4절은 결과, 5절은 해석과 한계를 담당한다. 같은 수치와 실패 사례를 여러 절에서 반복하지 않는다.
- 규칙은 수집에만 사용하고 추론은 학습한 Q값으로 행동을 고른다는 점을 명시한다. 시범 규칙을 직접 작성했다는 사실을 숨기지 않는다.
- 과제의 고정 조건과 본인이 선택한 설계를 구분한다. 가속 우선 구조, 규칙 기반 수집, 기본 보상 유지, 보수항 3.0은 과제의 의무 조건이 아니라 설계 선택이다.

### 중심 주장

> 항상 가속하며 이탈 없이 주행하는 조건에서, 출발 이후 속도가 상한 부근에 머물러 랩타임은 주행 경로 길이의 영향을 크게 받았다. 동일한 모델 구조·보상·학습 설정 아래 수집 규칙의 경로를 진단하고 개선하자, 최고 모델 기록도 19.40초에서 19.10초로 줄었다. 다섯 규칙 구성 중 세 구성에서는 최고 모델이 탐색 없는 규칙 주행보다 한 스텝인 0.02초 빨랐다.

해석할 때 구분할 사항:

- 제공 baseline 대비 개선은 **47.02 → 19.10초, 27.92초**다. 모델·수집 등 전체 구성의 차이가 포함된다.
- 본문의 중심인 규칙 도입 이후 개선은 **19.40 → 19.10초, 0.30초**다.
- `랩타임 ≈ 0.54 + 주행 거리 / 49.96`은 이 트랙에서 이탈 없이 계속 가속한 주행에 대한 경험적 근사다. 모든 정책에 적용되는 법칙이나 이론적 하한으로 쓰지 않는다.
- 보수항이 시범 정책의 복제를 강제한다고 주장하지 않는다. 이번 설정에서 모델의 기록과 경로가 시범 정책에 가까웠다는 관찰로 설명한다.

## 1. 데이터 수집 및 탐색 전략

**역할:** 보고서에서 가장 자세히 설명할 방법 절. 규칙을 도입한 이유, 도로를 인식하는 방식, 행동 결정, 탐색과 파라미터 선택을 연결한다.

### 1.1 규칙 수집으로 전환한 배경: 두 문장

> 규칙을 사용하지 않은 실험의 최고 깨끗한 기록은 39.80초였으며, 가속을 고정한 V1은 진행률 약 8.8%의 첫 코너를 넘지 못했다. 이에 고속 주행의 시범 데이터를 확보하기 위해 화면 기반 경로 추종 규칙을 수집에 도입했다.

V1의 결과를 V1b를 포함한 모든 변형에 일반화하지 않는다. 이전 실험 목록은 여기서 늘어놓지 않는다.

### 1.2 도로 인식과 경로 생성

수집 규칙의 처리 과정을 다음 순서로 설명한다.

1. **도로 영역 추출:** 96×96 RGB 관측에서 회색 도로에 해당하는 색상 조건으로 도로/비도로를 구분한다. 하단 계기판은 제외하고 차량에 가려진 영역은 보정한다. 차선 표시 검출이 아니라 **주행 가능한 도로 영역 추출**이라고 표현한다.
2. **경로점 추적:** 차량 앞 도로에서 시작해 1 단위씩 전진한다. 현재 방향 ±45° 범위에서 후보를 만들고, 경계까지의 거리와 방향 변화의 작은 벌점을 함께 평가해 다음 점을 고른다. 최종 설정의 방향 후보 간격은 5°다.
3. **방향 추정:** 경로를 따라간 거리 `s`에 대해 자연 삼차 평활 스플라인 `x(s), y(s)`를 맞추고 접선으로 방향을 계산한다. 최종 평활 계수는 λ=256이다.
4. **목표점 선택:** 앞쪽 도로의 방향 변화가 크면 조준 거리를 줄인다. 목표점은 원래 추적한 경로 위에서 잡고, 코너 안쪽으로 이동시켜 주행 거리를 줄인다.
5. **행동 선택:** 목표점 방향과 제어기의 조향 변화 한계를 고려해 좌·직진·우 중 하나를 선택하고 가속을 유지한다.

스플라인은 **방향 추정용**이다. 현재 구현에서 목표점을 스플라인 위에서 직접 고르는 것으로 설명하지 않는다. 5°는 도로 추적 후보의 방향 간격이며 차량의 실제 조향각 간격이 아니다.

수집과 추론의 차이는 다음 문장으로 명확히 한다.

> 수집 시에는 손으로 작성한 도로 추종 규칙이 행동을 정한다. 추론과 서버 채점에서는 이 규칙을 실행하지 않으며, CNN이 관측 영상과 영상에서 추출한 센서값으로 계산한 Q값의 최댓값 행동을 선택한다.

CNN에 도로 마스크나 스플라인을 별도 입력으로 제공한 것처럼 쓰지 않는다. 트랙 좌표를 읽는 측정용 제어기는 진단에만 사용했고, 수집 정책의 입력이나 학습 데이터 생성 정책으로 사용하지 않았다고 밝힌다.

### 1.3 탐색 전략과 선택 이유

- 확률 `1−ε`에서는 규칙 행동을 사용한다.
- `ε=0.1`에서는 **가속을 유지한 좌·직진·우 행동 1·5·6 중 하나를 무작위로 선택**한다. 모델의 argmax를 기본 행동으로 하는 일반 ε-greedy와 구분한다.
- 가속을 유지한 채 조향 주변 상태를 수집하려는 설계다. 제동·무가속 탐색으로 고속 주행 데이터가 줄어드는 것을 피하려 했다.
- ε=0.1은 제공값을 유지했다. 여러 ε를 비교해 최적값임을 입증했다고 쓰지 않는다.
- 10% 확률로 무작위 행동을 뽑아도 규칙과 같은 행동이 뽑힐 수 있으므로, 실제 행동이 정확히 10% 달라진다고 쓰지 않는다.

### 1.4 파라미터 선별과 실제 수집

- 규칙 후보는 먼저 학습 없이 공식 환경에서 주행시켜 비교한다.
- 최종 V1P4 선별에서는 **ε=0의 깨끗한 한 바퀴 기록**과 **ε=0.1의 20회 중 깨끗한 횟수**를 사용했다. V1P3a 규칙보다 빠르고 15/20 이상인 후보 중 선택했다.
- V1P4의 선택 결과는 규칙 19.12초, 탐색 평가 17/20 깨끗함, 깨끗한 중앙값 19.14초다.
- 이 20회 평가 절차가 모든 과거 단계에 똑같이 적용됐다고 소급해 쓰지 않는다.
- 주요 규칙별 새 수집·학습은 두 run으로 수행했다. 각 run은 c1에서 30회, 이후 c2~c10에서 각 10회로 총 120회 수집을 시도하고, 누적된 해당 run의 데이터로 학습했다.
- 실패·이탈 사례도 수집 통계에 포함한다. 데이터 전체가 깨끗한 시범 주행으로만 구성됐다고 쓰지 않는다. 실제 학습에 포함된 파일 수는 최종 모델의 학습 시점과 함께 확인한다.

최종 규칙 파라미터는 PDF에 중요한 값만 압축해 적는다. 전체 값은 다음과 같다.

### 그림 1. 수집 규칙의 도로 인식과 목표점 생성

- 실제 관측 화면 한 장 위에 추적 경로점, 방향 추정용 스플라인, 이동 전 목표점, 이동 후 목표점, 안쪽 이동 화살표를 표시한다.
- 스플라인은 방향 추정용 곡선이고 실제 차량 주행 궤적은 아니라는 점을 범례와 캡션에 명시한다.
- 작은 화면에서 색만으로 구분하지 않도록 점·선·화살표와 간단한 라벨을 함께 사용한다.
- 예시 캡션: **그림 1. 화면 기반 수집 규칙의 도로 경로 추적과 목표점 생성. 스플라인은 경로 방향 추정에만 사용하며, 추론 모델은 이 규칙을 실행하지 않는다.**

## 2. 보상함수 설계

**역할:** 실제 보상과 가중치를 명시하고, 기본 보상을 유지한 근거를 짧게 설명한다.

사용 보상은 기본값 그대로다.

```text
r_t = n_new × (1.0 + 0.5 × center_alignment)
      − 0.5 × I(도로 이탈)
```

- `n_new`: 해당 스텝에서 처음 방문한 도로 타일 수.
- `center_alignment`: 중앙 근접도, 0~1.
- 시간 벌점과 완주 보너스의 가중치는 모두 0.

유지 이유:

- 규칙 데이터에서 출발해 모델로 수집한 V1M과 중앙선 가점을 제거한 V1M5는 모두 최고 깨끗한 19.40초에 머물렀다.
- 그 이전 R1·R1b·R2도 비교 데이터 묶음에서 일관된 개선을 보이지 않았다. 이 내용은 배경 한 문장으로만 넣고 상세 표는 생략한다.
- 따라서 기본 보상을 유지하고, 개선 효과를 확인한 수집 경로에 집중했다.

표현은 **“시험한 보상 변경에서 최고 깨끗한 랩타임의 개선을 확인하지 못했다”**로 한정한다. 기본 보상이 불필요하다거나 보상함수는 일반적으로 영향이 없다고 결론내리지 않는다. 실패 실험의 숫자는 5절 표 3에 모아 중복을 줄인다.

| 항목 | 제공 기본 모델 | 사용한 모델: V1 기반 |

| 영상 특징 | 128차원 | 1024차원, 펼친 뒤 LayerNorm |
| 센서 결합 | 영상에서 추출한 센서 7개 결합 | 동일하게 센서 7개 결합 |
| 은닉층·출력 | Linear 135→9 | Linear 1031→128 → LayerNorm → ReLU → Linear 128→9 |
| 가속 선택 | 속도를 입력받는 학습 가능한 throttle head | throttle head 제거, 가속 행동 1·5·6에 +5의 가속 점수 부여 |

표에는 핵심 구조만 넣고, 출력 점수의 세부 결합은 공간이 허용할 때 본문 한 문장으로 설명한다. 제동 감점과 기본 행동 순서는 유지한다.

선택 이유:

- 네 층 CNN은 영상의 도로 형태와 공간 특징을 표현하기 위한 구성이다. 채널 수·층 수·은닉층 효과를 각각 분리해 입증했다고 주장하지 않는다.
- LayerNorm은 오프라인 Q 학습의 불안정을 완화할 목적으로 선택했다(Yue et al., 2023). 실제 실험에서는 Q 증가 자체가 뚜렷하게 억제되지 않았으므로, “Q 발산을 막았음을 입증했다”라고 쓰지 않는다.
- 가속 우선 구조는 고속 시범 데이터에 맞춰 행동 선택을 조향에 집중시키려는 설계다. 차량 속도를 수치적으로 상수에 고정한 것은 아니다.
- 입력 `(B,96,96,3)`, 출력 `(B,9)`, 행동 순서, 제공된 Double DQN 학습 코드는 유지했다.

학습 설정은 한 줄 또는 작은 표로 적는다.

> 보수항 3.0, 할인율 γ=0.99, Adam 학습률 3×10⁻⁴, 사이클당 epochs=5, batch size=64. 수집·학습을 반복하며 해당 run의 데이터를 누적했다.

보수항은 제공된 손실의 항을 사용한 것이다. 새 학습 알고리즘을 제안하거나 DQfD의 지도 손실을 구현했다고 설명하지 않는다.

- **깨끗한 완주:** 완주, 타일 273/273, 도로 이탈 0스텝.

## 5. 결과 분석

**역할:** 성능에 영향을 준 요소, 개선하지 못한 시도, 한계를 근거 범위 안에서 설명한다.

### 5.1 요소별 해석

1. **수집 경로:** 구조·기본 보상·학습 설정을 유지한 주요 단계에서 규칙 경로를 개선하자 모델 기록도 좋아졌다. 이번 실험 범위에서 수집 경로가 성능을 결정하는 주요 요인으로 관찰됐다.
2. **모델 구조:** 가속 우선 구조는 행동 선택을 조향에 집중시키는 설계였다. 규칙 데이터에 대한 학습을 가능하게 한 유일한 원인이라고 단정하지 않는다.
3. **보상·학습 설정:** 시험한 보상 변경, 보수항 감소, 할인율 증가에서는 당시 기준보다 빠른 깨끗한 후보를 얻지 못했다.
4. **시범 초과:** 다섯 규칙 구성 중 V1P2·V1P3a·V1P4의 최고 모델이 ε=0 규칙보다 0.02초 빨랐다. 이를 독립 학습 5회 중 3회의 성공률이나, 매번 한 스텝 빨라지는 법칙으로 해석하지 않는다. ε가 있는 수집 데이터의 최고 기록과 ε=0 규칙 기록도 구분한다.

최종 PDF에서는 위 표의 제목을 결과에 맞게 확정한다. V1P5가 개선하지 못하면 BG 6 행에 학습 결과를 합쳐 한 줄로 줄인다. 개선하면 표 2와 최종 모델·요약·서버 결과를 다시 정리한다. 사전 기준 미달 후보를 추가 실험했다면 그 사실도 짧게 밝힌다.

표에서 “추가 학습 대조군”과 “실패한 모든 후보의 judge”를 혼동하지 않는다. 공식 선택 후 judge가 계속 19.12초였던 것은 이전 가중치가 보존된 영향도 있다.

### 5.2 한계

- 손으로 작성한 시범 규칙에 크게 의존한다. 시범보다 0.02초 빠른 사례는 있었지만, 규칙을 크게 넘어서는 자율적인 경로 개선은 확인하지 못했다.
- 수집·개발·평가가 같은 고정 트랙에서 이루어졌다. 다른 트랙에 대한 일반화 성능은 평가하지 않았다.
- 주요 규칙별 새 수집·학습은 두 run씩이며, 사이클별 저장 모델은 서로 독립적인 반복 실험이 아니다.
- 최종 모델은 측정용 비교 경로보다 구간 합 약 0.039초 느리다. 이 차이가 모두 회수 가능하다거나 19.06초가 물리적 최적값이라고 주장하지 않는다.
- 92.5% 코너의 최소 바퀴 여유는 약 0.09로 작다. 이는 타일 경계를 직선으로 근사한 측정값이며, 엄밀한 안전 여유 보장은 아니다.

공간이 부족하면 위 한계를 3문장으로 묶되 규칙 의존, 고정 트랙, 반복 수와 경계 여유는 남긴다.
